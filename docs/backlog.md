# Backlog
## MVP
- [ ] 1. Jako pracownik chcę widzieć listę biurek i dokonać rezerwacji na konkretny dzień
- [ ] 2. Jako pracownik chcę móc anulować własną rezerwacje z poziomu zakładki "Moje rezerwacje"
- [ ] 3. Jako pracownik chcę zgłosić awarię na konkretnym biurku, podając krótki opis problemu
- [ ] 4. serwisant - aktualizuje atrybuty biurka (wyposażenie)
- [ ] 5. serwisant - zatrzymuje awarie i odblokowuje biurko
- [ ] 6. manager - pobiera raporty na temat awarii
- [ ] 7. pracownik - dostaje powiadomienia przypomnienie o wizycie
- [ ] 8. pracownik - dostaje powiadomienie o swojej awarii
- [ ] 9. serwisant - dostaje powiadomienie o awarii
- [ ] 10. manager - pobiera raporty na temat używania biurek
